# Generas Core Pricing

## Pricing Models

### 1. Hourly Rate
**Rate:** $30 - $50 per hour  
**Best for:** Consulting, code reviews, small fixes, ongoing support  

**Includes:**
- Development time
- Communication
- Basic documentation
- Bug fixes (within scope)

### 2. Fixed-Price Projects
**Starting from:** $500  
**Best for:** Well-defined projects with clear scope  

**Process:**
- Requirements analysis
- Detailed quote provided
- 50% upfront, 50% on completion
- Clear milestones and deliverables

**Typical Ranges:**
- Simple website: $500 - $1,500
- Web application: $2,000 - $10,000
- E-commerce platform: $3,000 - $15,000
- Custom AI solution: $5,000 - $25,000
- Enterprise system: $10,000 - $50,000+

### 3. MVP Development Package
**Price:** $2,000 - $5,000  
**Timeline:** 4 - 8 weeks  
**Best for:** Startups, idea validation  

**Includes:**
- Core features only
- Quick development
- Basic UI/UX
- Deployment to production
- Basic documentation
- 1 month support

### 4. Retainer Packages

**Bronze Retainer - $500/month**
- 10 hours per month
- Priority email support
- Bug fixes and small updates
- Monthly check-in

**Silver Retainer - $1,000/month**
- 25 hours per month
- Priority support (email + WhatsApp)
- Feature development
- Performance optimization
- Bi-weekly check-in

**Gold Retainer - $2,500/month**
- 70 hours per month
- 24/7 emergency support
- Full development work
- Strategic consulting
- Weekly check-in
- Architecture reviews

### 5. Startup Advisory
**Price:** $150 - $300 per session  
**Best for:** Early-stage startups, product strategy  

**Includes:**
- Technical roadmapping
- Architecture design
- Technology stack selection
- MVP planning
- Go-to-market technical strategy

## Payment Terms

### Standard Terms
- 50% upfront to start
- 50% on completion
- Payment via Bank Transfer, Mobile Money, or Crypto

### For Larger Projects ($10,000+)
- 30% upfront
- 40% at milestone
- 30% on completion
- Payment schedule aligned with milestones

### Retainers
- Monthly billing
- Paid in advance
- Unused hours don't roll over

## What's Included

### Always Included
- Source code
- Deployment to production
- Basic documentation
- 30-day bug fix warranty
- Ownership of all code and assets

### Optional Add-ons
- Extended support packages
- Additional documentation
- Training sessions
- Maintenance contracts
- Hosting setup

## What's Not Included

- Third-party service costs (hosting, APIs, domains)
- Ongoing maintenance (unless retainer)
- Major feature changes outside scope
- Content creation (copy, images, videos)
- Legal compliance (GDPR, etc.)
